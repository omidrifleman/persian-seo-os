# Spec 002 — تشخیص تصادم کیورد اعلام‌شده (cannibalization)

## چرا
چند صفحه برای یک fingerprint کیورد رقابت می‌کنند و جایگاه هم را می‌خورند.
مشاورهٔ پرارزش بدون API بیرونی.

## چه چیزی
تابع خالص که فهرست صفحات را می‌گیرد، با `keyword_fingerprint` گروه می‌کند،
و برای هر گروه ۲+ صفحه‌ای می‌گوید کدام بماند و بقیه چه کنند — با دلیل.

## محدودیت صریح
فقط «تصادم کیورد اعلام‌شده» (`target_keyword`). کانیبالیزیشن واقعی روی
کیوردی که هیچ صفحه اعلام نکرده فقط با GSC در برش بعدی است. ادعای پوشش کامل ممنوع.

## خارج از حوزه
کراول، شبکه، GSC، publish، noindex، اتصال به display_form.

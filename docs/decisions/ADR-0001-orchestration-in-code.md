# ADR-0001 — ارکستراسیون در کد، نه در n8n/Dify

**وضعیت:** پذیرفته‌شده

## زمینه
n8n و Dify سرعت پروتوتایپ را چند برابر می‌کنند.

## تصمیم
پروتوتایپ داخلی: مجاز. مسیر production و هر چیزی که به مشتری فروخته می‌شود: ممنوع.

## دلیل
- n8n با Sustainable Use License عرضه می‌شود؛ فروش سرویس مبتنی بر آن محدودیت دارد.
- Dify بند صریح منع راه‌اندازی محیط multi-tenant بدون لایسنس تجاری دارد — یعنی اگر هر مشتری یک workspace شود، نقض لایسنس است.
- دیباگ‌پذیری، تست‌پذیری و کنترل نسخه در کد به‌مراتب بهتر است.

## پیامد
ارکستراسیون با LangGraph یا کد خودمان + صف کاری (Celery/Temporal). ابزار بصری فقط برای آزمایش شخصی.

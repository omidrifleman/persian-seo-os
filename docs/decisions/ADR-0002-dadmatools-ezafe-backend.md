# ADR-0002 — DadmaTools به‌عنوان backend تشخیص ezafe

**وضعیت:** پذیرفته‌شده

## زمینه
تشخیص کسره اضافه برای سئوی فارسی لازم است و در خط فارسی معمولاً نوشته نمی‌شود.

## تحقیق لایسنس و تازگی
| فیلد | مقدار |
| --- | --- |
| URL | https://github.com/Dadmatech/DadmaTools |
| لایسنس | **Apache License 2.0** (فایل `LICENSE` روی `main` تأیید شد) |
| آخرین کامیت مشاهده‌شده | `2025-08-14` — SHA `8e779244` («Update setup.py») |
| دلیل انتخاب | ماژول اختصاصی `kasreh` برای تشخیص ezafe؛ مجاز برای استفاده تجاری؛ از قبل در `pyproject.toml` extras با کلید `nlp` آمده |

جایگزین لازم نشد — Apache-2.0 برای مسیر تجاری ما کافی است.

## تصمیم
- پکیج پایه بدون DadmaTools سبک می‌ماند.
- وابستگی: `optional-dependencies.nlp` با **پین دقیق** `dadmatools[full]==2.3.6`
  (`[full]` لازم است؛ base بدون torch/huggingface/tokenizers pipeline را import نمی‌کند).
- تابع عمومی پایدار؛ پیاده‌سازی پشت Protocol؛ **import تنبل**.
- Pipeline با `gpu=False` یک‌بار ساخته می‌شود.
- برچسب‌ها: هر چیزی غیر از `O` مثبت است؛ برچسب خام در `EzafeMark.raw_label`؛
  `confidence=None` وقتی بک‌اند امتیاز نمی‌دهد (None ≠ ۱.۰).
- بدون extras / بدون کش معتبر: خطای روشن.

## کش و آفلاین
- مسیر کش **فقط** از متغیر محیطی `PERSIAN_SEO_DADMA_CACHE` (مسیر مطلق) یا
  آرگومان مطلق صریح. مسیر نسبی `cache/dadmatools` استفاده نمی‌شود — به CWD وابسته
  است و از دایرکتوری دیگر می‌شکند.
- قبل از ساخت Pipeline، فایل‌های کلیدی از نظر وجود و حداقل اندازه چک می‌شوند؛
  دانلود ناقص → `EzafeCacheError` بلند (نه خرابی مبهم `torch.load` EOF).
- **مسیر آفلاین مستند:** مدل‌ها را یک‌بار روی ماشین دارای شبکه prefetch کن،
  پوشه کش را در ایمیج/ولوم mount کن، و `PERSIAN_SEO_DADMA_CACHE` را به همان مسیر
  مطلق بده. Dropbox و HuggingFace از داخل ایران قابل اتکا نیستند.

## تست
- سوئیت پیش‌فرض: فقط mock / واحدی، بدون شبکه.
- یکپارچگی واقعی: `PERSIAN_SEO_NLP_TESTS=1` (+ کش آماده و extras).

## ریسک‌های عملیاتی
1. دانلود مدل در runtime از شبکه — برای ایران محدودیت واقعی.
2. حجم torch — extras اختیاری؛ ایمیج پایه بدون `[nlp]`.
3. deps در metadata پایه ناقص‌اند — فقط `[full]` کافی است.
4. برچسب runtime: رشته‌های BIO-مانند (`S-kasreh` / `O`)؛ موجودی برچسب بسته نیست
   (مقاله V2 BIO گفته، خروجی واقعی `S-kasreh` بوده).
5. کش نسبی ممنوع؛ فقط env مطلق + بررسی ناقص‌بودن فایل.
6. مسیر آفلاین: mount کش از پیش آماده + `PERSIAN_SEO_DADMA_CACHE`.

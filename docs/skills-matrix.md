# نقشه اسکیل‌های پروژه

نسخه کامل و توضیح‌دار این نقشه در صفحه Notion نگه‌داری می‌شود.
این فایل خلاصه‌ای است که ایجنت کدنویس هنگام تصمیم فنی به آن رجوع می‌کند.

| حوزه | اسکیل‌های حیاتی | ابزار پیش‌فرض ما |
| --- | --- | --- |
| NLP فارسی | نرمال‌سازی، ZWNJ، ezafe، lemma، embedding فارسی، کلاسترینگ | DadmaTools (Apache-2.0)، Hazm، پکیج خودمان |
| سئوی تکنیکال | کرال، ایندکس، canonical، اسکیما، Core Web Vitals، لاگ سرور | Scrapy + Playwright، advertools، Lighthouse |
| داده سئو | GSC API، GA4، DataForSEO، Trends، autocomplete، مدل تخمین حجم | GSC اول، DataForSEO دوم |
| مهندسی LLM | prompt، RAG، evaluation، بنچمارک فارسی، کنترل هزینه توکن | LLM Gateway خودمان |
| بک‌اند | Python/FastAPI، Postgres، صف، idempotency، multi-tenancy، RLS | FastAPI + Postgres + Celery |
| MCP و ایجنت | طراحی tool، schema، LangGraph، حلقه بازخورد | mcp + LangGraph |
| فرانت‌اند | Next.js، RTL کامل، diff viewer، صف بازبینی، گزارش فارسی | Next.js + Tailwind (RTL) |
| DevOps | داکر، CI، مهاجرت DB، رصد، هوست دوبخشی ایران/خارج | Docker Compose → K8s بعداً |
| انطباق و ریسک | سیاست spam گوگل، E-E-A-T، لایسنس اوپن‌سورس، حریم داده | ADRها + گِیت کیفیت |
| رشد و فروش | productized service، قیمت‌گذاری، کیس‌استادی، GEO/AEO | مرحله ۲ اولین درآمد |

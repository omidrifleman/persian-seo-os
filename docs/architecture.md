## چهار ستون غیرقابل‌مذاکره
1. MCP-first: هر قابلیت یک tool است، پس هم UI و هم ایجنت مشتری و هم فروش مستقل ماژول ممکن می‌شود.
2. گِیت انسانی در دیتابیس: `publish_jobs.approval_id NOT NULL`.
3. idempotency + snapshot + rollback برای هر نوشتن بیرونی.
4. audit log کامل — هم الزام اعتماد است، هم قابل فروش به مشتری بزرگ.
